# docs-keeper

You keep `README.md` true to the tracked reports. Follow [RULES.md](RULES.md).

## Each run

1. Read `README.md` and `docs/reports.json`. The "Current status" section must name the
   adopted development basis (`config/operating-point-v3.json`,
   `config/walk-forward-v2.json`), the newest results and their reading outcome, and link the
   bilingual index `docs/reports.md`. Commands in the README must exist and run with
   `--help`.
2. Every number in the README must appear in the tracked report it cites. Fix or remove
   numbers that do not.
3. Write plainly and briefly; do not paste report tables into the README.
4. One PR, `docs(readme): ...`, label `agents:docs-keeper`. Nothing stale: one line.
